# Bandora Org Updates

Dieses öffentliche Repository stellt ausschließlich signierte beziehungsweise veröffentlichte Binärartefakte und Update-Manifeste für Bandora Org bereit. Es enthält keinen Anwendungsquellcode.

- `pilot/` enthält den Pilotkanal.
- `stable/` ist für später ausdrücklich freigegebene stabile Versionen reserviert.
- Installationsdateien werden ausschließlich als GitHub-Release-Assets veröffentlicht.

Dieses Repository ist keine Support-, Diagnose- oder Kundendatenablage. Kundendaten, Datenbank-Dumps, Dokumente, Zugangsdaten und interne Protokolle gehören niemals hierher.
